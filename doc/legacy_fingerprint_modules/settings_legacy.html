NTP Server Setup
Gib hier NTP-Server ein (z.B. "pool.ntp.org" oder "time.google.com"). Mehrere Server können durch Komma getrennt werden. Lokale Server sind ebenfalls möglich (z.B. "192.168.111.1, europe.pool.ntp.org, pool.ntp.org, time.google.com").

Die Zeitinformation wird für Zeitstempel im Log-Panel verwendet. Wenn kein Server erreichbar ist oder keine Zeitquelle angegeben wird, bleibt die Systemzeit ungenau bzw. auf null gesetzt.
Zeitzone: %NTP_OFFSET_NAMEN%: %NTP_OFFSET_TIME%
  • Wähle eine Zeitzone aus dem Dropdown-Menü.
  • In der manuellen Auswahl kann man ganz individuell eine Zeitzone eingeben.
  • Zum Beispiel "Wunschbezeichnung | Zeitzone", z.B. "Berlin | GMT-1" oder einfach nur das Zeitformat "GMT-1".
  • Das sind Zeitformate (Zeitzone), die man eingeben kann: "GMT-1", "UTC-1", "Etc/GMT-1". Und das ist ein Format für Berlin mit automatischer Zeitumstellung: "CET-1CEST,M3.5.0,M10.5.0/3".
  • Hier alle Zeitzonen
Trage hier den Breitengrad ein, im Format 48.77444. Wenn dieses Feld leer bleibt, wird die sonnenbasierte Beleuchtung der Türklingel deaktiviert.
Trage hier den Längengrad ein, im Format 11.619619. Wenn dieses Feld leer bleibt, wird die sonnenbasierte Beleuchtung der Türklingel deaktiviert.
Wenn kein Offset angegeben wird, bleibt die Klingelbeleuchtung aus, und auf der Anzeige steht "Aus". Bei einem Offset von 0 schaltet sich das Licht genau bei Sonnenaufgang und -untergang ein.

Du kannst den Zeitpunkt des Sonnenaufgangs und -untergangs beeinflussen, indem du eine positive oder negative Zahl eingibst. Die maximale Anpassung beträgt dabei >99 Minuten.

Alternativ kannst du eine feste Uhrzeit im Format "HH:MM" eingeben, zu der die Beleuchtung eingeschaltet wird.


WiFi Stability Setup
Bei sehr schwachem Signal startet eine weiche WLAN-Rettung. Die gespeicherten WLAN-Zugangsdaten bleiben unveraendert. Verwendet wird der zuletzt gemerkte beste AP derselben SSID oder ein einmalig frisch gesuchter AP. Die Mindestverbesserung fuer normales Roaming spielt dabei keine Rolle.
Bei schwachem Signal wird hoechstens einmal pro Minute nach dem besten AP derselben SSID gesucht. Der beste Fund wird gespeichert. Ein Wechsel passiert nur, wenn der neue AP mindestens um die eingestellte Signalverbesserung besser ist. Bei ausreichend gutem Signal wird nicht gescannt.
Legt fest, wie viel besser ein anderer AP sein muss, damit beim normalen Roaming gewechselt wird. Dieser Wert ist eine dB-Differenz und kein RSSI-Wert in dBm.
