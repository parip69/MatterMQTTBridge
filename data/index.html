Button bearbeiten ⚙️
  • Button-Legende: Der Button ist standardmäßig auf 0.5 Sekunde eingestellt.
  • **Das Ändern der Buttons machen Sie weiter unten unter "Button bearbeiten".**
  • **Wichtig:** Mit einer Raute "#" im Button-Namen wird der Button ausgeblendet, unabhängig von Position der Raute!
  • **(0) Berührungssensitiver Ring deaktivieren:**
    - Bei diesem Button braucht man keine Schaltzeit eingeben.
    - Jeder Button repräsentiert einen Ausgang (Relais) und zeigt den aktuellen Zustand an.
    - Durch Klicken auf diesen Button wird der berührungsempfindliche Ring am Fingerscanner deaktiviert, um Fehlauslösungen durch Regen zu verhindern.
  • **(1) Relais 0.5 Sekunden ist die Standard-Schaltzeit:**
    - Indem du eine Zahl vor den Namen setzt, legst du die neue Schaltzeit des Relais fest.
    - Jeder Button repräsentiert einen Ausgang (Relais) und zeigt den aktuellen Zustand an.
    - Durch Klicken auf diesen Button wird der Ausgang für 0.5 Sekunde geschaltet.
  • **(2) Relais 0.5 Sekunden ist die Standard-Schaltzeit:**
    - Indem du eine Zahl vor den Namen setzt, legst du die neue Schaltzeit des Relais fest.
    - Jeder Button repräsentiert einen Ausgang (Relais) und zeigt den aktuellen Zustand an.
    - Durch Klicken auf diesen Button wird der Ausgang für 0.5 Sekunde geschaltet.
  • **(3) Relais 0.5 Sekunden ist die Standard-Schaltzeit:**
    - Indem du eine Zahl vor den Namen setzt, legst du die neue Schaltzeit des Relais fest.
    - Jeder Button repräsentiert einen Ausgang (Relais) und zeigt den aktuellen Zustand an.
    - Durch Klicken auf diesen Button wird der Ausgang für 0.5 Sekunde geschaltet.
  • **(4) Relais 0.5 Sekunden ist die Standard-Schaltzeit:**
    - Indem du eine Zahl vor den Namen setzt, legst du die neue Schaltzeit des Relais fest.
    - Jeder Button repräsentiert einen Ausgang (Relais) und zeigt den aktuellen Zustand an.
    - Durch Klicken auf diesen Button wird der Ausgang für 0.5 Sekunde geschaltet.
  • **(5) Klingel-Pin (Output 5) - Klingel schalten: Der Button ist standardmäßig auf eine 1 Sekunde eingestellt.**
    - Indem du eine Zahl vor den Namen setzt, legst du die neue Schaltzeit des Relais fest.
    - Jeder Button repräsentiert einen Ausgang (Relais) und zeigt den aktuellen Zustand an.
    - Durch Klicken auf diesen Button wird die Klingel für die eingestellte Zeit geschaltet.
    - Dies ist ein vollwertiger Output-Pin wie die anderen auch (Pin 21).
  • **(6) Klingel Auto-Funktion - Ein/Aus:**
    - Bei diesem Button braucht man keine Schaltzeit eingeben (wird ignoriert).
    - Durch Klicken auf diesen Button wird die automatische Klingel-Auslösung aktiviert oder deaktiviert.
    - Wenn aktiviert: Klingel läutet, wenn kein Finger erkannt wurde.
    - Wenn deaktiviert: Klingel läutet nicht automatisch bei unbekannten Fingern.
📖
  • ⚠️ Wichtig - Button für MQTT deaktivieren mit Grad-Zeichen (°):
    - Wenn ein "°" irgendwo im Button-Namen vorkommt (egal ob Anfang, Mitte oder Ende), wird der Button für alle MQTT-Schaltbefehle deaktiviert (auch im Broker- und Client-Modus).

    • - Es erfolgt keine Reaktion auf MQTT-Schaltbefehle, auch nicht über die API.
    - Die lokale Schaltung über das Webinterface bleibt möglich, aber MQTT wird blockiert.
  • ⚠️ Wichtig - Button EIN-/AUSBLENDEN mit Raute (#):
    - Wenn ein "#" irgendwo im Button-Namen vorkommt (Anfang, Mitte oder Ende), wird der Button ausgeblendet (optisch unsichtbar).
    - Der Button bleibt funktionsfähig, ist aber nicht sichtbar.
    - Sie können den Button beliebig benennen und mit "#" ein- oder ausblenden!
  • ⚠️ Wichtig - MQTT-Publish unterdrücken mit Stern (*):
    - Wenn ein "*" irgendwo im Button-Namen vorkommt (egal ob Anfang, Mitte oder Ende), wird keine MQTT-Nachricht beim Schalten über das Webinterface gesendet.
    - Die lokale Schaltung bleibt erhalten, aber MQTT-Publish wird blockiert.
    - Dies gilt für alle Buttons (Relais, Klingel, Ring etc.).
  • ⚠️ Wichtig - Button DEAKTIVIEREN mit 0 am Anfang:
    - Wenn Sie eine "0" am Anfang des Button-Namens setzen (z.B. "0 Garage"), wird der Button deaktiviert.
    - Der PIN bleibt dann LOW und reagiert NICHT auf Fingerabdrücke.
    - Der Button bleibt sichtbar, funktioniert aber nicht!
  • Button-Beschriftung ändern:
    - Das Formular ermöglicht das Ändern der Beschriftung (Label) für jeden Button.
    - Der Benutzer kann den gewünschten Button aus dem Dropdown-Menü auswählen.
    - Die neue Beschriftung wird automatisch gespeichert.
  • Schaltdauer mit Nummer voranstellen (optional):
    - Die Standard-Schaltdauer beträgt 0,5 Sekunden (500 Millisekunden).
    - Durch Voranstellen einer Zahl vor den Button-Namen können Sie die Schaltdauer ändern.
    - Beispiele: "1 Garage" = 1 Sekunde, "2 Einfahrt" = 2 Sekunden, "5 Tor" = 5 Sekunden.
    - "0 Eingang" = deaktiviert (PIN bleibt LOW, nicht funktional).
  • Praktische Beispiele:
    - "#Garage" → Button ausgeblendet (Raute am Anfang, optisch unsichtbar)
    - "Garage#" → Button ausgeblendet (Raute am Ende, optisch unsichtbar)
    - "Ga#rage" → Button ausgeblendet (Raute in der Mitte, optisch unsichtbar)
    - "0 Garage" → Button deaktiviert (sichtbar, aber funktioniert nicht)
    - "Garage" → 0,5 Sekunden Schaltdauer (Standard, sichtbar und aktiv)
    - "3 Haupteingang" → 3 Sekunden Schaltdauer (sichtbar und aktiv)

Der Sensor verfügt über 200 Speicherplätze für die Speicherung von Fingerabdrücken. Die gewählte Platznummer wird auch als ID verwendet, wenn Übereinstimmungen per MQTT veröffentlicht werden.

    - Der Sensor verfügt über 200 Speicherplätze für Fingerabdrücke.

    - Wichtig: "UserName Relais -1" oder "UserName Relais -1234" Die Zahl am Ende steht für ein Relais, wobei "0" eine deaktivierte Benutzerrolle bedeutet.
    - Individuelle Benutzernamen erleichtern die Verwaltung.
    - Der eingegebene Benutzername wird über MQTT veröffentlicht.

    - Klicke auf "Anmeldung starten", um einen Fingerabdruck hinzuzufügen oder zu ersetzen.
